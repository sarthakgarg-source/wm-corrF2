# wm-BREAK — conventions for Claude Code
Study I. Read README.md, GLOSSARY.md, LOGIC.md. `python run_all.py` → `python make_report.py` → `python checks.py` after any edit to a module.
- Parameters in config.py only. Weekly only.
- Every number in report prose is computed from a table. make_report.py is the CLEAN report built around four chapters (asset classes / signal / volatility / returns); each chapter keeps the shape `_q` question → `_ans` one-line answer → chart → `_walk` ("how we know — look at the chart": what to look at and where) → table → `_tiles` key numbers → `_book` what it means for the book → `_details` for the rest; §0 = the answers, §1 = one sell-off (the March-2020 N100 flip) walked through every measure; Part II folded away. Jargon goes through `_d(term)` (hover definition from TERMS) and is said in plain words first. make_report_full.py keeps the five-part scaffold with everything expanded; make_guide.py builds the reading guide (questions, chart-by-chart readings per combination, column dictionary). Keep all three building; a new chart or column goes into the guide too.
- Every study that uses the group correlation G also runs for every pair (`sigcorr.pair_corrs`; tables `<name>_pairs`; `figs._add_pairs` draws the ten lines — index solid, gold dashed/legendonly, `PAIR_COL` one colour per pair). A new G study gets its pair version in the same commit.
- Chart titles are findings with the numbers in them (computed in figs.py from the same table), the method goes in `_layout(..., subtitle=...)`, and a boxed annotation points at where the finding shows. Never a method-only title.
- Forward windows use t+1.. only (checks.py pins it in pairs.forward and replace). Ten episodes / six sell-offs: ranks and medians, never t-stats. t-stats elsewhere are Newey-West and need n ≥ 20.
- The deviation z-score decays by construction; never read "z came back" as "the ratio came back" — test reversion on the ratio's later change (`6_z_forward`).
- Secrets live in `.env` only. Synthetic data is never read as a result.
- Charts: figs.py (Plotly) is what the report uses; plots.py (PNG) is optional and must keep working. A new chart goes into figs.FIGS and is embedded with `_img(name, **kw)`; the div id must be unique (kwargs are appended).
- Add any new column to GLOSSARY.md in the same commit. Python 3.11: no same-quote nesting inside f-strings — precompute joined strings.
- Lead/lag claims use `vol.lead_lag_blocks` (X on t−L+1 … t, Y on t+1 … t+L — no shared week; NW t and the non-overlapping sub-sample both required). `vol_corr_lead*` (overlapping 13-week changes) is kept for reference only; never read a lead off it.
- Hit rates are computed on the weeks that have a forward return (`.dropna()` before `> 0`), never on the bucket's full week count.
- Forward returns in the quintile charts are `C.QUINT_FWD` (4) weeks; the 13-week columns stay in the tables. The ratio study (`histcorr.ratio_study`) is the pair-level "who wins" test — correlation and signal cuts, past-4-week sign, next 4 weeks.
- No person's name anywhere — not in code comments, docstrings, chart text, docs or the change log (write 'the review of <date>', 'the desk', 'as agreed'). `WM_REDACT_NAMES` in `.env` drives the hygiene check; the list itself never goes into a tracked file.
